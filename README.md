# Tessera downloads

Beta application downloads for Tessera by Thorn & Reason. Application source is maintained separately.

## Current beta: 0.2.0-beta.2

- [Apple Silicon Mac installer](https://github.com/Thorn-and-Reason/Tessera-releases/releases/download/v0.2.0-beta.2/Tessera_0.2.0-beta.2_darwin-aarch64.dmg)
- [Intel Mac installer](https://github.com/Thorn-and-Reason/Tessera-releases/releases/download/v0.2.0-beta.2/Tessera_0.2.0-beta.2_darwin-x86_64.dmg)
- [Windows ARM64 installer](https://github.com/Thorn-and-Reason/Tessera-releases/releases/download/v0.2.0-beta.2/Tessera_0.2.0-beta.2_windows-aarch64-setup.exe)
- [Windows x64 installer](https://github.com/Thorn-and-Reason/Tessera-releases/releases/download/v0.2.0-beta.2/Tessera_0.2.0-beta.2_windows-x86_64-setup.exe)
- [Linux x64 AppImage](https://github.com/Thorn-and-Reason/Tessera-releases/releases/download/v0.2.0-beta.2/Tessera_0.2.0-beta.2_linux-x86_64.AppImage)

On Windows ARM, choose the ARM64 installer for a native installation. Existing x64 installations continue to receive x64 updates. Save your work, close the app, and install the ARM64 package manually to switch architecture. Preserve the app-data folder and your saved files.

All five updater packages have verified signatures bound to this version. Mac packages are ad-hoc signed and unnotarised. Windows packages lack Authenticode; native Windows ARM installation, GUI use, and updates remain untested on hardware.
